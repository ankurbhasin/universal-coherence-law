# Stub only - not full analysis code

This repository does **not** contain the full analysis pipeline for the
Universal Coherence Law results.

- All Python files under `src/phase_tools/` are structural stubs.
- They describe module names, command line interfaces, and high level
  logic in plain language.
- They are not executable end to end and do not reproduce figures
  or tables in the paper.

The complete, reproducible code and data will be released after peer review
and acceptance or at the author's discretion. Until then this repository
acts as a public pointer and priority record.

If you are a reviewer or editor and require access to the full pipelines,
please contact the author directly.
